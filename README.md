<h1>CUB3D</h1>
This project is inspired by the world-famous Wolfenstein 3D game, which was the first FPS ever. <br>
It enables to explore ray-casting. The goal is to make a dynamic view inside a maze, <br> in which you'll have to find your way. <br>
This project’s objectives are : rigor, use of C, basic algorithms, information research. <br>
As a graphic design project, cub3D enables to improve the skills in these
areas: windows, colors, events, fill shapes.
